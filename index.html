2e · Active Hunt — autonomous discovery crawler

What this does: instead of you pasting URLs, the crawler builds search queries from your watchlist + high-severity codebook terms, asks each platform connector for public candidates, scores them, and drops threats into the review queue for a human. Nothing is auto-reported or auto-actioned. Connectors use official platform APIs / approved access only — no private content, no credential stuffing. Demo mode uses a synthetic connector (no live calls).

2f · BrandGuard™ — advertiser brand-safety adjacency

For licensing advertisers & agencies: when an advertiser connects their ad account and turns monitoring on, BrandGuard continuously scans the public content in their ad context and flags every case where their brand runs beside content Project Spear categorizes as harmful — extremism, drugs, child-safety, and the rest. This is the licensable brand-safety search over the same intelligence base.
Advertiser sign-in & monitoring (licensing tenant)
Authorization is via the advertiser's ad-account OAuth / the platform's marketing API — the system learns where their ads run. No password is handled and the system never logs in as them. Public content only.
